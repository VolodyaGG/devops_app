# Найденные уязвимости

При сканировании с помощью trivy возникла уязвимость с пакетом scarlette: CVE-2024-47874

В Starlette до версии 0.40.0 парсер multipart/form-data имел баг: хакер мог отправить специальный запрос с огромным количеством мелких частей или некорректными разделителями. Это заставляло сервер бесконечно обрабатывать данные, съедая весь CPU.

Уязвимость была исправлена установкой обновленного пакета FastAPI версии 0.135.1
